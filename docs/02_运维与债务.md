## 一、启动与运维

```bash
bash start.sh --daemon    # 一键后台启动（自动 kill 旧进程）
bash start.sh --status    # 查看状态
bash start.sh --stop      # 停止所有
bash start.sh             # 前台调试（日志打到终端）
tail -f logs/main.log     # 实时日志
```

启动后拉起三个服务：

| 服务 | 身份 | 渠道 | API |
|------|------|------|-----|
| `main.py` 主进程 | investment Bot（群1） | 飞书 WS | `AI_*_INVEST` 中转站 |
| 子进程 | investment_ds Bot（群2） | 飞书 WS | `AI_*_DS` DeepSeek 直连 |
| `scheduler_runner.py` | 每日报告（定时任务） | APScheduler | — |

### 双 Bot API 配置（.env）

```bash
# 群1 Invest Bot（中转站 Claude）
AI_MODEL_INVEST=openai/claude-sonnet-4-6
AI_API_BASE_INVEST=https://api.chr1.com/v1
AI_API_KEY_INVEST=sk-xxx

# 群2 DS Bot（DeepSeek 直连）
AI_MODEL_DS=openai/deepseek-v4-pro
AI_API_BASE_DS=https://api.deepseek.com/v1
AI_API_KEY_DS=sk-xxx

ENABLE_INVEST_BOT=true   # false 则仅 DS Bot 启动
```

云端改 `.env` 后必须 `pm2 restart invest-main --update-env`。

## 六、常见报错速查

| 现象 | 真实原因 | 处理方法 |
|------|---------|----------|
| 报告返回 `⏸️ 限流` | Gemini 免费配额耗尽（429） | **自动处理**：内置降级链会依次尝试 2.0-flash → 1.5-flash |
| 报告返回 `❌ API Key 认证失败` | key 错误或过期（401） | 更新 `.env` 中的 `GEMINI_API_KEY` 后重启 |
| 报告不发送但日志无错 | 飞书 Token 过期或网络 | 查 `logs/daily_report.log`，检查飞书应用状态 |
| Bot 收不到消息 | WS 连接断开 | `bash start.sh --status` 确认进程，可重启 |

## 七、技术债务（已知问题，当前无 Bug，触发条件出现时再修）

### TD-01：Skill 反向 import executor（循环依赖）

```python
# 所有 Skill 里写了：from core.executor import get_ai_provider
# 方向相反，但 Python 运行时可处理（函数体内 import）
```

**触发条件**：core/ 打包为独立库时
**修复方案**：把 `get_provider` 在 executor 中注入到 `ctx.metadata`，Skill 从 ctx 取

### TD-02：dedup Hook 使用进程内全局变量

```python
_processed_ids: set = set()  # 进程内
```

**当前安全**：每 Bot 独立进程 + 独立飞书应用，message_id 不跨 Bot
**触发条件**：同一飞书应用多进程部署时

### TD-03：kb_query 硬编码知识库目录结构

```python
cards_dir = Path(ws) / '研究' / '论点卡'  # 硬编码
```

**触发条件**：知识库目录重命名时
**修复方案**：目录结构配置到 `bot.yaml` 的 `knowledge_dirs` 字段

### TD-05：daily_report Bot 不走标准管道

**现状**：scheduler_runner.py 自治，有自己的 `_audit()` 函数
**触发条件**：需要对定时任务统一监控时
**修复方案**：开发 scheduler Channel 类型

### 债务优先级总览

| 编号 | 当前危险性 | 触发条件 | 改动成本 |
|------|-----------|---------|---------|
| TD-01 | 🟢 无 | core 打包复用 | 中（改所有 Skill） |
| TD-02 | 🟢 无 | 同飞书应用多进程 | 低（改 dedup.py）|
| TD-03 | 🟡 低 | 目录重组 | 低（改1处）|
| TD-05 | 🟡 低 | 定时任务统一监控 | 中（新 Channel）|

> **行动原则**：不需要现在修，出现对应触发条件时按方案优化。
