## 一、一键启动（最常用）

```bash
cd /home/zy/investment_system
bash start.sh --daemon
```

> ⚠️ **每次启动前会自动 kill 所有旧进程**，无需手动清理。可任意重复执行。

启动后会拉起三个服务：

| 服务 | 身份 | 渠道 |
|------|------|------|
| `main.py` 主进程 | investment Bot (Claude) | 飞书 WS |
| 子进程 | investment_ds Bot (DeepSeek) | 飞书 WS |
| `scheduler_runner.py` | 每日报告 Bot（定时任务）| APScheduler |

---

## 二、常用运维命令

```bash
# 查看运行状态
bash start.sh --status

# 停止所有服务
bash start.sh --stop

# 前台调试模式（日志直接打到终端）
bash start.sh

# 查看实时日志
tail -f logs/main.log
tail -f logs/daily_report.log

# 重启（一键：先 kill 旧的，再启动新的）
bash start.sh --daemon
```

## 五、数据源架构（无幻觉原则）

| 数据 | 来源 | 时效 |
|------|------|------|
| A股大盘实时指数 | akshare 东方财富 `stock_zh_index_spot_em` | 实时 |
| A股行业板块涨跌 | akshare 东方财富 `stock_board_industry_name_em` | 实时 |
| 恒生指数 | yfinance `^HSI` | 实时 |
| 恒生科技指数 | akshare `stock_hk_index_spot_em`（精确匹配名称）| 实时 |
| 财联社快讯/午间精选 | akshare `stock_info_global_cls` | 实时 |
| **华尔街见闻早餐** | wallstcn.com API，标题含"华尔街见闻早餐" | 每日约7:30 |
| **华尔街见闻午间收评** | wallstcn.com API，标题含"午间收评" | 每日约11:30 |
| **华尔街见闻早间要闻汇总** | wallstcn.com API，标题含"早间要闻汇总" | 每日约12:30 |
| 美股/商品/港股收盘 | yfinance | T+1（隔夜） |
| 国内期货 | tushare `fut_daily` | T+1 |
| 北向资金 | tushare `moneyflow_hsgt` | T+1（有延迟）|

**防幻觉原则**：所有数字由 `data_fetcher.py` 抓取，AI 不生成任何价格/涨跌幅。字段标注 `[数据缺失]` 或 `[暂未发布]` 时，AI 写"数据暂缺"，不得补充推测。

## 六、Bot 功能速查

### investment Bot（Claude，飞书群1）

| 指令 | 功能 |
|------|------|
| `s` | 系统状态 |
| `h` | 帮助 |
| `录 [内容]` | 录入情报（AI智能路由P7/P11）|
| `问 [问题]` | 知识库问答 |
| `析 [行业] [问题]` | 行业底稿分析 |
| `比 [A] [B]` | 两行业横向对比 |
| `总 [主题]` | 汇总分析 |
| `蒸馏` / Phase触发词 | 执行投研Phase（P1-P11）|
| `ok` / `确认` | 确认写入 |
| `改 [意见]` | 修改待确认内容 |
| URL | 自动抓取并录入 |

### investment_ds Bot（DeepSeek，飞书群2）

功能与 investment Bot 相同，使用 DeepSeek 模型（更快响应，适合日常问答）。
