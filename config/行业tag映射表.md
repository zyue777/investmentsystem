# 行业 Tag 映射表
# Industry Tag Mapping Table

> 本文件是情报卡打 tag 的唯一参考基准。
> Phase07 蒸馏时，遇到以下产业链品种，必须按映射规则补全父级 tag，不得只打子品种。

---

## 使用规则

打 tag 时，**从下往上**沿产业链补全所有层级：
- 子品种 tag（必填）
- 产业链位置 tag（若有）
- 上游原料 tag（若文章实质涉及上游供需）

**禁止**将多个层级合并为一个 tag（如禁止写 `原奶深加工`，必须拆成 `原奶` + `深加工`）。

## 乳制品产业链

```
原奶（上游原料）
  └── 液态奶（直接消费）
  └── 深加工（加工品类，统一父级 tag）
        ├── 奶酪
        ├── 黄油
        ├── 稀奶油
        ├── 全脂奶粉
        ├── 脱脂奶粉
        ├── 乳清蛋白
        ├── 酪蛋白
        └── 乳蛋白
```

**映射规则**：

| 文章核心品种 | 必须同时打的 tag |
|---|---|
| 奶酪 / 黄油 / 稀奶油 / 乳清蛋白 / 酪蛋白 / 乳蛋白 / 全脂奶粉 / 脱脂奶粉 | `原奶` + `深加工` + 具体子品种 |
| 原奶供需（不涉及深加工品种） | `原奶`（不打 `深加工`） |
| 乳制品行业整体（跨多品类） | `原奶` + `乳制品`（不强制打 `深加工`，除非文章实质讨论深加工） |

**示例**：
- 奶酪行业研究 → tags: `原奶`, `深加工`, `奶酪`
- 原奶存栏数据 → tags: `原奶`
- 乳企Q1财报（伊利/蒙牛） → tags: `原奶`, `乳制品`

## 锂电产业链

```
锂矿（上游资源）
  └── 锂盐（碳酸锂 / 氢氧化锂）
        └── 锂电池（正极材料 / 电芯 / PACK）
              └── 储能 / 动力电池（应用端）
```

**映射规则**：

| 文章核心品种 | 必须同时打的 tag |
|---|---|
| 碳酸锂 / 氢氧化锂 | `锂盐`（不写"锂"） |
| 锂矿 | `锂矿`（不写"锂盐"） |
| 锂电池 / 正极材料 | `锂电池`（不上溯到锂矿，除非文章实质讨论矿端） |
| 储能 | `储能`（不强制带 `锂电池`，除非文章实质讨论电芯） |

## 有机硅产业链

```
工业硅（上游原料）
  └── 有机硅单体
        └── 有机硅（下游应用）
```

**映射规则**：涉及有机硅单体/下游应用时，若文章实质讨论工业硅供需，补打 `工业硅`；否则只打 `有机硅`。
