# Phase 2 — 月度深研生成

[触发词: "撰写全景报告分析", "生成某大类的月度深度报告", "执行极限生存测试"]

## 任务目标

读取初步筛选池中的行业，利用行业图谱、网络搜索和私有知识库，提取量化数据，生成格式统一的月度深度分析报告。

## 数据流与读取规则

- **源输入文件**: 限定读取 `行业筛查/困境反转/screened_input.md`。
- **权限分类**:
  - Phase 2A 仅处理属于 `01A_成长周期型.md` 的行业。
  - Phase 2B 仅处理属于 `01B_刚需供需型.md` 的行业。
  - C类、D类品种严禁生成报告。

## 自动分卷协议

当单次输入的目标行业超过 10 个时，强制执行分卷处理：

1. 依据行业大类（如农化、化工、矿石）将其拆分为独立的文件卷（如卷一、卷二）。
2. 每完成一卷，立即将其保存至 `研究/周报月报/当月/卷X_[大类名称]_全景评价.md`。
3. 同步将已完成进度和剩余待处理列表追加至 `研究/周报月报/当月/_batch_status.md`。
4. 继续执行下一卷。如遇模型上下文极限提示，输出当前进度并通知用户重跑以继续。

## 外部搜索白名单机制

- 允许的现货与开工率数据源：生意社、百川盈孚、卓创资讯、Mysteel、SMM、USDA。
- 禁用的数据源：一切散户股票论坛和社交平台（股吧、雪球、小红书、知乎等）。
- 若无法从白名单信源中获取目标字段，强制填入 `[数据黑洞]`，严禁使用模型预训练知识库推断数字。

## 认知框架依赖

报告生成前，参考以下逻辑文件：

- `投资哲学/通用投研大心法.md`
- `投资哲学/当下关注焦点.md`
- `研究/论点卡/[行业名]_研究底稿.md`（若存在，必须加载并以其中的反转条件、传导关系作为分析约束）

## 强制输出结构

每份行业分析报告必须包含以下三部分，**严格按此顺序执行**：

### 【步骤 1】因果逻辑链先行判定

**在查看任何数据之前**，基于以下输入完成逻辑判定：

- `投资哲学/通用投研大心法.md`（该行业属于工业品看需求还是农业品看供给？）
- `研究/论点卡/[行业名]_研究底稿.md`（若存在：读取历史周期规律、反转充分条件、当前位置判断）
- `知识库/行业/`（按 YAML tags 匹配） 中 ≤ 90天的情报卡

输出内容：

1. **本行业反转的核心因果链**（1-3 条因果链，每条格式：[起因] → [传导] → [结果]）
2. **当前这条因果链走到了哪一步**（明确标注：尚未启动 / 正在传导 / 已部分兑现 / 已被证伪）
3. **需要哪些数据来验证上述判断**（列出具体指标名称，这将指导步骤 2 的检索方向）

> ⚠️ 铁律：如果该行业不存在研究底稿、且图谱中标注为 `⏳ 待填充`，则在因果链判定中必须显式声明 `[逻辑框架缺失——本次分析基于通用逻辑，判断置信度降级]`。

### 【步骤 2】数据验证与核查

针对步骤 1 中明确需要验证的指标，打开并读取 `行业状态面板.md`，逐项检索。

**数据补全规则**：

搜索公开网络结束后，若表格中仍存在缺失，必须对 `知识库/行业/`（按 YAML tags 匹配） 执行扫描（提取文件名日期距今 ≤ 90天的文件）。存在包含该指标具体数字的情报时，替换为：`{数值}【知识库补充 YYYY-MM-DD】`。如果知识库中仍未记录，则标注 `[待验证]`，严禁伪造。

| 指标名称 | 验证目的（对应哪条因果链） | 提取数值 | 数据获取日期 | 来源渠道 |
| :------- | :------------------------- | :------- | :----------- | :------- |
|          |                            |          |              |          |

**关键区分**：

- 数据支持了因果链 → 正常推进分析
- 数据与因果链矛盾 → 必须显式标注 `[逻辑-数据冲突⚠️]` 并展开讨论，不得回避
- 数据缺失 → 标注 `[待验证]`，因果链判断保留但注明置信度

### 【步骤 3】卷末汇总宽表

在本卷全部行业分析完成后，输出最终统计表格（此表旨在对齐下游 Phase 3 的分类要求）：

| 细分行业 | 核心因果链（一句话） | 当期价格 | 现金成本估算 | 深亏持续时长(月) | 复产周期估算 | 因果链验证状态 | 信息盲点 |
| :------- | :------------------- | :------- | :----------- | :--------------- | :----------- | :------------- | :------- |
|          |                      |          |              |                  |              |                |          |
