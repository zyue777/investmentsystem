# Phase 2-Pre — 行业初研底稿生成

## 触发词

「帮我初步研究一下XX行业」「给我出一份XX的研究底稿」「初研XX」

---

## 第一步：赔率范式判定（模板路由）

在开始研究前，先根据行业特征判断所属范式，选择对应模板：

| 特征 | 范式 | 选用模板 | 管道 |
| :--- | :--- | :--- | :--- |
| 行业正在深度亏损，有高复产壁垒，供给将自然萎缩 | **α困境反转** | `_模板_α困境反转.md` | Phase 1.5 → 2/3/5 |
| 未来3-5年供需结构性紧平衡/短缺，关注个股产能弹性 | **γ供需紧缩成长** | `_模板_γ供需紧缩.md` | Phase 2-Pre → 9 |
| 供需稳定 + 估值便宜 + 高股息，标的极少 | **β价值红利** | 不需完整底稿，出一张论点卡即可 | 01E 手工池 |

> ⚠️ 如果不确定，先按α模板生成草稿，在用户Review时讨论是否转γ。

---

## 第二步：信息搜集（网络+知识库）

1. **网络扫描**（必须使用最新数据，严禁旧数据描述现状）：
   - 该行业当前供需格局、产能周期位置
   - 当前盈亏状态（亏损面、亏损时长、行业利润vs历史分位）
   - 近期重大事件（政策、灾害、技术突破、贸易摩擦）
   - 核心高频指标（价格、库存、开工率）的最新值与历史分位

2. **知识库比对**：
   - 读取 `研究/知识库/` 下该行业相关情报卡（按 `industry:` 标签筛选）
   - 读取关联行业的情报卡（上下游、宏观关联）

3. **大心法校准**：
   - 确认品种分野：工业品（大行情靠需求）还是农业品（大行情靠供给）
   - 按对应分野法则调整分析重心

---

## 第三步：按模板生成底稿草稿

### α困境反转型：须覆盖的分析框架（参考 `_困境反转研究模板.md` 7步）

| 模板节 | 对应困境反转7步 | 必填要点 |
| :--- | :--- | :--- |
| 一、定性 | — | 一句话 + 品种分野 + 核心驱动力 |
| 二、价格研判 | §7 终局判断 | 分阶段研判表 + 铁底(现金成本) + 反弹目标(完全成本) |
| 三、反转条件 | — | 内部出清 + 外部压制解除 + 财务底 |
| 四、标的 | §4 成本曲线 | 龙头逻辑 + 成本梯队定量 + 股票表 |
| 五、供给法则 | §5 产能出清 | 时滞参数 + 退出壁垒 + 复产速度 |
| 六、供需平衡 | §1 盈亏现状 + §3 供需测算 | 动态监控卡 + 历史复盘表 |
| 七、进出口 | §6 进出口 | 贸易地位 + 进口平价 + 代差 |
| 八、逻辑总结 | §7 非线性推演 | 二阶导数思维 + 不可持续性判断 |
| 九、历史案例 | — | 库存/产能消化规律 |
| 十、指标体系 | §2 监测指标 | 3-5个高频指标 + 当前值 + 3年分位 |

### γ供需紧缩型：须覆盖的核心维度

- 供需缺口趋势（未来3-5年供需平衡表）
- 供给约束清单（为什么上不来）
- 在建产能盘点表
- 需求刚性评估
- 成本曲线分位
- 产能弹性选股（赔率公式）

---

## 第四步：输出规范

1. 输出第一行必须标注文件路径，格式：
   `FILE_PATH: 研究/论点卡/YYYY-MM-DD_[行业名]_研究底稿.md`
2. 之后空一行，按模板格式生成完整草稿（Part A/B/C/D 四板块）
3. **对不确定的数据/判断明确标注置信度**（参考原奶底稿的防幻觉标注方式）
4. 系统将根据 FILE_PATH 自动落盘，⚠️ **需等待用户 Review 确认后才写入**

---

## 防幻觉约束

- 严禁使用"很高""大幅"等模糊词，必须提供具体数据
- 无法获取的数据直接标注"暂无公开数据，建议查阅XX"，严禁编造
- 关键数据在句末标注来源（Wind / 公司公告 / USDA / 海关总署等）
- 区分客观事实与主观判断，主观判断用括号标注来源
