# Phase 10 — 周度投资备忘提炼

[触发词: "提炼本周备忘", "融合这周的想法", "消化 memo"]

## 任务目标

扫描 `08_Investment_Memos/_Inbox/` 中过去 7 天的碎片化投资思考，分类提炼有价值的内容，判断哪些认知值得反哺到核心框架文件中。

## 数据流

- **输入**：`08_Investment_Memos/_Inbox/` 中日期距今 ≤ 7 天的文件
- **产出**：`08_Investment_Memos/_Weekly_Digest/YYYY-WXX_周度认知提炼.md`
- **潜在触达**：大心法 / 当下关注焦点 / 论点卡 / 01E 特别池（仅建议，等用户确认后才修改）

## 执行步骤

### 步骤 1：扫描与归类

读取 Inbox 中过去 7 天的全部文件内容，按以下四类提取：

| 类别 | 定义 | 反哺目标 |
| :--- | :--- | :--- |
| 行业洞察 | 对某个行业供需/价格/产能的新认知 | 论点卡 / 图谱 / 当下关注焦点 |
| 投资案例 | 具体标的的投资逻辑、估值判断 | 01E 特别池 / 论点卡第五节 |
| 复盘反思 | 对过去投资决策的回顾和教训 | 大心法 / 论点卡第八节 |
| 策略迭代 | 对投资方法论的升级思考 | 大心法 / 全局系统提示词 |

### 步骤 2：价值判断

对每条提取的内容做判断：

- **高价值**：包含新的因果逻辑、颠覆了已有认知、或填补了认知盲区 → 建议写入核心文件
- **中等价值**：有参考意义但尚未成熟 → 记录在周度提炼中，暂不反哺
- **低价值/重复**：已知信息或碎片过小 → 仅在提炼中提及，不做反哺

### 步骤 3：生成周度提炼报告

输出格式：

```markdown
# YYYY-WXX 周度认知提炼

## 本周 memo 统计

- 总条数：X
- 高价值：X | 中等：X | 低价值：X

## 高价值认知提取

### [类别] 标题
- **原文摘要**：...
- **新认知/新逻辑**：...
- **建议反哺至**：[目标文件] 的 [具体章节]
- **建议修改内容**：...

## 中等价值记录

- ...

## 建议操作清单

| 序号 | 操作 | 目标文件 | 变更描述 |
| :--- | :--- | :--- | :--- |
| 1 | 新增/修改 | 论点卡/XX_研究底稿.md | 补充第六节跨行业传导关系 |
```

### 步骤 4：等待确认

⚠️ 周度提炼报告展示后，**必须等待用户逐条确认或批量确认**后，才可修改核心框架文件。禁止自动修改大心法、论点卡等核心文件。

## 文件存储

周度提炼报告 → `08_Investment_Memos/_Weekly_Digest/YYYY-WXX_周度认知提炼.md`
